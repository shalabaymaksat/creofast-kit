# creofast — телефоннан таргет креатив монтажы

Камераға сөйлеген селфи-видеоңды Claude Code өзі монтаждайды:
- кідірістер, ыңылдау және қайта бастаған жерлер қиылады;
- басында қызыл хук, бүкіл видеода 2–3 сөздік субтитр;
- айтылған сөзге сай B-roll: Claude логотипі, сан стикерлері, Ads Manager анимациясы + сенің өз скриндерің, пікірлерің, рилстерің;
- дайын видео сенің репоңа түседі: `creofast/ready/<аудитория>/`.

## Не керек (бір рет)
1. **Claude Pro немесе Max** жазылымы (телефондағы Claude Code тек ақылы жоспарда).
2. **GitHub аккаунты** және кез келген өз репоң (бос болса да болады). Жоқ болса: github.com → New repository → атын жаз → Private → Create.
3. Claude қолданбасы → **Code** → репоңды таңда → environment баптауы → **Network access: Full** (бағдарлама мен Whisper моделін жүктеу үшін).

API кілт керек емес: сөзді тануды (Whisper) сессияның өзі жасайды.

## Монтаж жасау
1. Видеоны Google Drive-қа сал → Бөлісу → **Anyone with the link** → сілтемені көшір.
2. Claude Code-қа (өз репоңда) осыны жаз:

```
Осы нұсқаулықпен монтаж жаса: https://github.com/shalabaymaksat/creofast-kit/blob/main/SKILL.md
Видео: <Google Drive сілтемесі>
```

3. Claude мәтінді, хукты және B-roll жоспарын көрсетеді → түзет немесе «дұрыс» де.
4. ~5–10 минуттан кейін видео репоңда: GitHub қолданбасы → репо → `creofast/ready/…` → файл → Download.

## Өз активтерің (міндетті емес)
Бірінші монтаждан кейін репоңда `creofast/assets/` папкалары пайда болады. Оларға файл салсаң (GitHub қолданбасы не github.com → Add file → Upload), B-roll бай болады:

| Папка | Не салу керек | Қашан шығады |
|---|---|---|
| `results/` | табыс, сатылым, жарнама кабинеті скриншоттары | «табыс», «N млн таптық», «аналитика» |
| `photos/` | клиент пікірі, хабарлама суреттері | «клиент жазды», «пікір» |
| `reels/` | өз рилстерің (тік видео, 5–15 с) | «рилс», «контент» |
| `cases/` | клиент/оқушы нәтижелері (тік видео) | «нәтиже», «оқушыларым жасады» |
| `works/` | портфолио (жатық видео) | «жұмыстарым» |
| `long/` | бір ұзын видео үзіндісі (1–2 мин) | «ұзын видеоны қиып рилс жасау» |

Бір файл 25 MB-тан аспасын. Активсіз де жұмыс істейді: хук, субтитр, қию, логотип, сан стикерлері, Ads Manager анимациясы әрқашан бар.

## Ескерту
- Бірінші іске қосу орнатуға және Whisper моделін жүктеуге 3–5 минут алады; бір видео рендері ~4 минут.
- Репоңды **Private** ұста — ішінде өз видеоларың мен скриндерің болады.

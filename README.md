# creofast — телефоннан таргет креатив монтажы

Камераға сөйлеген селфи-видеоңды Claude Code өзі монтаждайды:
- кідірістер, ыңылдау және қайта бастаған жерлер қиылады;
- басында қызыл хук, бүкіл видеода 2–3 сөздік субтитр;
- айтылған сөзге сай B-roll: Claude логотипі, сан стикерлері, Ads Manager анимациясы + сенің өз скриндерің, пікірлерің, рилстерің, клиент нәтижелерің;
- дайын видео аудитория папкасына (`ready/<сегмент>/`) түседі.

## Не керек
- **GitHub аккаунты** (тегін) және телефонда GitHub қолданбасы.
- **Claude Pro немесе Max** жазылымы (Claude Code веб/телефонда тек ақылы жоспарда).
- **Groq API кілті** (тегін): console.groq.com → API Keys → Create API Key.

## Орнату (бір рет, ~5 минут)
1. Осы беттің жоғарғы жағындағы **Use this template → Create a new repository** → атын жаз, **Private** таңда → Create. Енді өз көшірмең бар.
2. Телефонда Claude қолданбасы → **Code** (немесе claude.ai/code) → GitHub-ты қос → өз `creofast` репоңды таңда.
3. Environment баптаулары:
   - **Network access:** Full
   - **Environment variables:** `GROQ_API_KEY=` + Groq кілтің
4. (Міндетті емес, бірақ ұсынылады) өз активтеріңді `assets/my/` ішіне сал — төмендегі кесте.

## Әр видеоны монтаждау
1. Видеоны Google Drive-қа сал → «Anyone with the link» сілтемесін көшір. (25 MB-тан кіші болса, GitHub қолданбасы арқылы `inbox/`-қа да салуға болады.)
2. Claude Code-қа жаз: **«creofast: осы видеоға монтаж жаса <сілтеме>»**
3. Claude мәтінді, хукты және B-roll жоспарын көрсетеді → түзет немесе «дұрыс» де.
4. Бірнеше минуттан кейін видео `ready/<сегмент>/` ішінде → GitHub қолданбасы → Code → ready → файл → Download.

## Өз активтерің — `assets/my/`
Неғұрлым көп салсаң, B-roll соғұрлым бай. Файлдарды GitHub қолданбасы не github.com арқылы сәйкес папкаға жүкте (бір файл ≤25 MB).

| Папка | Не салу керек | Қашан шығады |
|---|---|---|
| `results/` | табыс, сатылым, жарнама кабинеті скриншоттары (png/jpg) | «табыс», «N млн таптық», «аналитика» |
| `photos/` | клиент пікірі, хабарлама, сертификат суреттері | «клиент жазды», «пікір» |
| `reels/` | өз рилстерің (тік видео, 5–15 с үзінді жеткілікті) | «рилс», «контент», «YouTube» |
| `cases/` | клиент/оқушы нәтижелері (тік видео) | «нәтиже», «оқушыларым жасады» |
| `works/` | портфолио, мықты жұмыстарың (жатық видео) | «жұмыстарым», «монтаж» |
| `long/` | бір ұзын видео (подкаст/эфир, 1–2 мин үзінді) | «ұзын видеоны қиып рилс жасау» |

Активсіз де жұмыс істейді: хук, субтитр, қию, логотип, сан стикерлері және Ads Manager анимациясы әрқашан бар.

## Ескерту
- Бұлтта бірінші іске қосу ffmpeg/mediapipe орнатады (2–3 мин).
- Бір видео рендері ~4 минут. Нәтиже файлы 100 MB-тан кіші болуы керек (30–60 с видео — 10–30 MB).
- Репоңды **Private** ұста: ішінде өз видеоларың мен скриндерің болады.

# creofast — таргет креатив монтажы (бұлттағы / телефондағы Claude Code)

Бәрі репо ішінде: `engine/` (скрипттер), `assets/my/` (пайдаланушының өз B-roll активтері), `fonts/`, `models/` (MediaPipe), `templates/`. Нәтиже `ready/<сегмент>/` → commit + push, пайдаланушы GitHub қолданбасынан жүктейді.
Пайдаланушы қай тілде жазса, сол тілде жауап бер (қазақша / орысша).

## 0. Орта (сессия басында бір рет)
```bash
bash setup.sh                 # ffmpeg + numpy/pillow/requests/mediapipe; GROQ_API_KEY тексереді
python3 engine/assets.py      # өз активтерін дайындайды + қай B-roll қолжетімді екенін басады
```
- GROQ_API_KEY жоқ болса — тоқта, айт: console.groq.com → API Keys → тегін кілт жасап, claude.ai/code → environment → Environment variables-ке `GROQ_API_KEY=...` қосу. Кілтті чатқа жазуды сұрама.
- Желі жабық болса (api.groq.com, Google Drive ашылмаса) — environment Network access-ті «Full»-ға қою керек.
- `assets/my/` бос болса — монтаж бәрібір жасалады (хук, субтитр, қию, логотип, сан стикерлері, Ads Manager), бірақ бір рет айт: өз скриндері/рилстері/пікірлері `assets/my/<санат>/`-қа салынса, B-roll бай болады (README кестесі).

## 1. Видеоны алу + жоба
Видео `inbox/`-та (GitHub арқылы салынған, ≤25 MB) немесе сілтеме (Google Drive/Dropbox, «Anyone with the link»):
```bash
python3 engine/new_project.py <жоба_аты> IMG_0001.MOV
python3 engine/new_project.py <жоба_аты> "https://drive.google.com/file/d/…/view"
cd projects/<жоба_аты>; export RAZBOR_WORK=$PWD/ RAZBOR_SRC=$PWD/src/; E=../../engine
```
`list.txt` — видеолар нөмірі (01, 02…, әліпби ретімен). Орысша видео: `export CREO_LANG=ru`.

## 2. Транскрипция
```bash
RAZBOR_PROMPT="<видеодағы терминдер, өнім аты>" python3 -W ignore $E/stt_chunks.py N
python3 -W ignore $E/stt_turbo.py N
python3 -W ignore $E/phr.py N 0.18            # фраза-фраза → stt/NN.phr.json
python3 -W ignore $E/verify_fill.py N 0.22     # ыңылдау
python3 $E/seg.py a b whisper-large-v3-turbo kk "терминдер" NN   # сенімсіз фразаны қайта тыңдау
```
Қазақша STT қателеседі — нұсқаларды салыстырып, мағынасына қарай қалпына келтір.

## 3. Мәтін + хук + B-roll жоспарын пайдаланушыға көрсет — БЕКІТПЕЙ РЕНДЕР ЖОҚ
Чатта: нөмірленген мәтін (сенімсіз жер **[?]**), хук (CAPS, тырнақшада, аудиторияға сұрақ: «КАФЕ ИЕСІ, КЛИЕНТ АЗАЙДЫ МА?»), B-roll жоспары (қай сөзде не — тек қолжетімді эффектілер), сегмент (кімге арналған: папка аты). Пайдаланушы түзетеді → сосын ғана әрі қарай.

## 4. Конфиг
- `videos.py`: `VIDEOS[N] = dict(hook=…, y_off=0, hook_x=540, hook_y=1300, sub_y=335, keys=KEYS, play=[], ig=False, seg='01_…', text="""…""")` — мәтін бекітілген, кіші әріп, әр жол бір сөйлем, латын терминдер өз күйі. `KEYS` — жуан шығатын кілт сөздер.
- `cuts.py`: қайта бастаған/қайталанған жерлер `N: [(a, b)]` (бастапқы секунд) — `phr.json`-нан бір ойды екі рет бастағанды тап.
- `broll2.py`: `N: [E('сөз', ұзақтығы, спек), …]` — **сөздер айтылу ретімен**. Актив жоқ спек (None) өздігінен түседі.

## 5. Рендер (фонда) + тексеру
```bash
../../engine/chain.sh 1 2 3     # run_in_background; маска → рендер (~4 мин/видео) → freeze → ready/<seg>/
```
Прогресс `out/chain.log` (`DONE N -> seg/файл | []`). Әр видеоны көзбен тексер:
```bash
ffmpeg -v error -y -i out/01_*.mp4 -vf "fps=1/2.5,scale=216:384,tile=8x2" -frames:v 1 test/sheet01.jpg   # Read арқылы қара
grep "fx \|!!" out/01.logb      # !! табылмады = сөз реті қате; <1 с эффект = жыпылықтау
```
Түзет → қайта `chain.sh N`.

## 6. Тапсыру
```bash
cd ../..; git add ready/ projects/<жоба>/videos.py projects/<жоба>/broll2.py projects/<жоба>/cuts.py
git commit -m "creofast: <жоба> дайын"; git push
```
Пайдаланушыға: файл жолы `ready/<сегмент>/NN_….mp4`, GitHub қолданбасында Code → ready → файл → Download. 100 MB-тан үлкен файл push болмайды (30 с видео ~10–20 MB).

## B-roll ережелері (айтылғанды сөзбе-сөз көрсет)
| Айтылғанда | Спек (`engine/lib.py`) | Актив |
|---|---|---|
| Claude / ChatGPT / жасанды интеллект | `logo('L'/'R')` | керек емес |
| сан, баға, уақыт, пайыз | `stat('500К ₸', 'бір айда')`, `stat(…, pos=CHEST)` | керек емес |
| жарнама іске қосу, кабинет | `ADS` | керек емес |
| табыс, сатылым, аналитика, «N млн таптық» | `result(i, hl=[(0,0.38,1,0.48)])` | `results/` |
| пікір, клиент жазды, хабарлама | `photo(i)` | `photos/` |
| рилс, контент, YouTube | `ORB_MY`, `WALL_MY`, `reel(i)` | `reels/` |
| нәтиже, оқушылар/клиенттер жасады | `ORB_ST`, `STK_ST` | `cases/` |
| жұмыстарым, портфолио, монтаж | `STK`, `work(i)` | `works/` |
| ұзын видеоны қиып рилс жасау | `CUT` | `long/` + `reels/` (≥2) |
Сөзге сай актив жоқ болса — B-roll қоспа (ұқсас бірдеңе қойма), не `stat`-пен ойдың сан жағын көрсет.

## Тексеру тізімі
- Бет жабылмасын: бет кадрда төмен болса (бас үсті y>450) стикерді `pos=CHEST`-ке түсір; ұзын стикер мәтінін қысқарт; orbit бетті кессе `('orbit', …, dict(ss=0, center=(540, 1680)))`.
- Хук алғашқы 3,8 с кеудеде; кеуде эффектілері одан кейін басталады (автомат).
- Келесі эффект алдыңғысын кеседі (логотиптен басқасы) — 1 с-тан қысқа қалғанын алып таста.
- `freeze` нәтижесі `[]`; блюр/зум ауысу жоқ; сөз айтылмай тұрып экранда шықпайды.

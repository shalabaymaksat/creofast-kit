# creofast — таргет креатив монтажы

Сен (Claude Code) осы нұсқаулықты пайдаланушы берген сілтемеден оқыдың. Монтаж **пайдаланушының өз репосында** жасалады: қозғалтқыш `~/creofast-kit`-ке жүктеледі, ал жұмыс файлдары мен дайын видео — `<репо>/creofast/` ішінде.
Пайдаланушы қай тілде жазса, сол тілде жауап бер. Техникалық сөзді аз қолдан, қадамды қысқа айт.

## 0. Орта (сессия басында бір рет)
```bash
[ -d ~/creofast-kit ] && git -C ~/creofast-kit pull -q || git clone -q --depth 1 https://github.com/shalabaymaksat/creofast-kit ~/creofast-kit
bash ~/creofast-kit/setup.sh                                  # ffmpeg + numpy/pillow/requests/mediapipe; GROQ_API_KEY тексереді
source ~/creofast-kit/env.sh && python3 $E/assets.py          # жұмыс папкасы + қолжетімді B-roll тізімі
```
- **Shell күйі командалар арасында сақталмайды** — әр Bash командасын `source ~/creofast-kit/env.sh && …` деп баста (`$E` = engine, `$CREO_HOME` = `<репо>/creofast`).
- `git clone` не `pip` желіге шыға алмаса → тоқта, айт: Claude Code environment баптауында **Network access → Full** қою керек, сосын жаңа сессия ашу.
- `GROQ_API_KEY жоқ` → тоқта, айт: console.groq.com → API Keys → Create API Key (тегін), сосын environment баптауы → **Environment variables** → `GROQ_API_KEY=<кілт>` қосып, жаңа сессия ашу. Кілтті чатқа жазуды сұрама.
- `<репо>/creofast/assets/` бос болса — монтаж бәрібір жасалады (хук, субтитр, қию, логотип, сан стикерлері, Ads Manager). Бір рет айт: өз скриндерін/рилстерін/пікірлерін сол папкаларға салса, B-roll бай болады (кесте төменде).

## 1. Видеоны алу + жоба
Видео: Google Drive/Dropbox сілтемесі («Anyone with the link» болуы керек) немесе репоға салынған файл (`creofast/inbox/`).
```bash
source ~/creofast-kit/env.sh && python3 $E/new_project.py <жоба_аты> "https://drive.google.com/file/d/…/view"
```
Жоба: `$CREO_HOME/projects/<жоба_аты>/`; `list.txt` — видео нөмірлері (01, 02…). Жүктеу сәтсіз болса (HTML/шағын файл) — сілтеме жабық, «Anyone with the link»-ті тексеруді сұра.
Ары қарай әр команда: `source ~/creofast-kit/env.sh && cd $CREO_HOME/projects/<жоба_аты> && export RAZBOR_WORK=$PWD/ RAZBOR_SRC=$PWD/src/ && …`
Орысша видео: `export CREO_LANG=ru` (транскрипцияның барлық қадамына).

## 2. Транскрипция
```bash
RAZBOR_PROMPT="<видеодағы терминдер, өнім/бренд аты>" python3 -W ignore $E/stt_chunks.py N
python3 -W ignore $E/stt_turbo.py N
python3 -W ignore $E/phr.py N 0.18            # фраза-фраза → stt/NN.phr.json
python3 -W ignore $E/verify_fill.py N 0.22     # ыңылдау
python3 $E/seg.py a b whisper-large-v3-turbo kk "терминдер" NN   # сенімсіз фразаны қайта тыңдау
```
Қазақша STT қателеседі — нұсқаларды салыстырып, мағынасына қарай қалпына келтір.

## 3. Мәтін + хук + B-roll жоспарын көрсет — БЕКІТІЛМЕЙІНШЕ РЕНДЕР ЖОҚ
Чатта қысқа:
1. нөмірленген мәтін (сенімсіз жер **[?]**);
2. хук — CAPS, тырнақшада, аудиторияға сұрақ/айбар («КАФЕ ИЕСІ, КЛИЕНТ АЗАЙДЫ МА?»);
3. B-roll жоспары — қай сөзде не (тек `assets.py` қолжетімді деп басқандар);
4. аудитория папкасы (`01_кафе_иелері` т.с.).
Пайдаланушы түзетеді немесе «дұрыс» дейді → сосын ғана әрі қарай.

## 4. Конфиг (жоба папкасында)
- `videos.py`: `VIDEOS[N] = dict(hook='“…”', y_off=0, hook_x=540, hook_y=1300, sub_y=335, keys=KEYS, play=[], ig=False, seg='01_…', text="""…""")` — мәтін бекітілген, кіші әріп, әр жол бір сөйлем, латын терминдер өз күйі. `KEYS` — жуан шығатын кілт сөздер.
- `cuts.py`: қайта бастаған/қайталанған жерлер `N: [(a, b)]` (бастапқы видео секундтары) — `phr.json`-нан бір ойды екі рет бастағанды тап.
- `broll2.py`: `N: [E('сөз', ұзақтығы_с, спек), …]` — **сөздер айтылу ретімен**. Актив жоқ спек (None) өздігінен түседі.

## 5. Рендер (фонда) + тексеру
```bash
$E/chain.sh 1 2 3     # run_in_background; маска → рендер (~4 мин/видео) → freeze → $CREO_HOME/ready/<seg>/
```
Прогресс `out/chain.log` (`DONE N -> seg/файл | []`, `FAIL` болса `out/NN.logb` / `masks/N.log`). Әр видеоны көзбен тексер:
```bash
mkdir -p test && ffmpeg -v error -y -i out/01_*.mp4 -vf "fps=1/2.5,scale=216:384,tile=8x2" -frames:v 1 test/sheet01.jpg   # Read арқылы қара
grep "fx \|!!" out/01.logb      # !! табылмады = сөз реті қате; <1 с эффект = жыпылықтау
```
Түзет → қайта `chain.sh N`.

## 6. Тапсыру
```bash
cd "$(git rev-parse --show-toplevel)" && git add creofast/ && git commit -m "creofast: <жоба> дайын" && git push
```
(`creofast/.gitignore` аудио/маска/уақытша файлдарды өзі шығарып тастайды.) Пайдаланушыға: файл жолы `creofast/ready/<папка>/NN_….mp4`; жүктеу — GitHub қолданбасы → репо → Code → creofast → ready → файл → Download. 100 MB-тан үлкен файл push болмайды (30–60 с видео ~10–30 MB). Push сәтсіз болса — тармақ/рұқсат қатесін айт, видео сессия ішінде қалғанын ескерт.

## B-roll ережелері (айтылғанды сөзбе-сөз көрсет)
Кітапхана: `$E/lib.py`. Өз активтері: `<репо>/creofast/assets/<папка>/`.
| Айтылғанда | Спек | Актив папкасы |
|---|---|---|
| Claude / ChatGPT / жасанды интеллект | `logo('L')` / `logo('R')` | керек емес |
| сан, баға, уақыт, пайыз | `stat('500К ₸', 'бір айда')`, `stat(…, pos=CHEST)` | керек емес |
| жарнама іске қосу, кабинет | `ADS` | керек емес |
| табыс, сатылым, аналитика, «N млн таптық» | `result(i, hl=[(x0,y0,x1,y1)])` (0..1 үлесі) | `results/` скриншоттар |
| пікір, клиент жазды, хабарлама | `photo(i)` | `photos/` |
| рилс, контент, YouTube | `ORB_MY`, `WALL_MY`, `reel(i)` | `reels/` тік видео |
| нәтиже, оқушылар/клиенттер жасады | `ORB_ST`, `STK_ST` | `cases/` тік видео |
| жұмыстарым, портфолио | `STK`, `work(i)` | `works/` жатық видео |
| ұзын видеоны қиып рилс жасау | `CUT` | `long/` + `reels/` (≥2) |
Сөзге сай актив жоқ болса — B-roll қоспа (ұқсас бірдеңені «толтыру үшін» қойма); санды `stat`-пен көрсетуге болады.

## Тексеру тізімі
- Бет жабылмасын: бет кадрда төмен болса (бас үсті y>450) стикерді `pos=CHEST`-ке түсір; ұзын стикер мәтінін қысқарт; orbit бетті кессе `center=(540, 1680)`.
- Хук алғашқы 3,8 с кеудеде; кеуде эффектілері одан кейін басталады (автомат).
- Келесі эффект алдыңғысын кеседі (логотиптен басқасы) — 1 с-тан қысқа қалғанын алып таста.
- `freeze` нәтижесі `[]`; блюр/зум ауысу жоқ; сөз айтылмай тұрып экранда шықпайды.
- Пайдаланушының видеосы мен активтерін реподан тыс жерге жіберме (тек Groq STT).
